wasm-vips without threads

Runs the wasm-vips release build and a build without threads in your browser. Each run makes every WordPress image size as JPEG and WebP and takes about half a minute. The findings are in the repository.

Run in this browser

  • Without threads, normal page Finishes and shows the images.
  • Release build, normal page Fails after 60 seconds.
  • Release build, isolated page Finishes. Compare its time with the first run.

An isolated page reloads itself once before the run starts.

Try it in WordPress

  • Open WordPress Playground Add an image block and upload an image.
More runs
  • Without threads, 4 workers, normal page
  • Without threads, 4 workers, with AVIF, normal page
  • Release build, 4 workers, isolated page
  • Without threads, 4 workers, isolated page
  • Release build, 4 workers, with AVIF, isolated page

The query string takes lib (baseline or nothreads), jobs, iters (default 5) and avif=1.
